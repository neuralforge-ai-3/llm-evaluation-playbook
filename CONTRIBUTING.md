# Contributing Guidelines

Thank you for contributing to the LLM Evaluation Playbook.

## Development Standards

- Use Python 3.11 or newer.
- Follow PEP 8 conventions.
- Add pytest tests for new functionality.
- Document API interfaces clearly.
- Use type annotations where appropriate.

## AI Engineering Guidelines

- Never commit API keys or credentials.
- Do not include sensitive production data.
- Document model and prompt versions.
- Add evaluation examples for AI features.
- Validate generated responses before deployment.

## Pull Requests

1. Create a feature branch.
2. Implement focused changes.
3. Add relevant tests or documentation.
4. Describe the changes clearly.
5. Request review when appropriate.
