# LLM Evaluation Playbook

Practical engineering patterns for building,
evaluating, and monitoring production LLM applications.

## Technology Stack

- Python
- FastAPI
- LangChain and LangGraph
- OpenAI and Anthropic APIs
- PostgreSQL and pgvector
- Redis
- Kafka
- OpenTelemetry
- Docker and Kubernetes

## Key Topics

### LLM Evaluation
- Faithfulness and groundedness
- Hallucination detection
- Prompt regression testing
- LLM-as-a-judge evaluation

### RAG Systems
- Document retrieval
- Embedding pipelines
- Vector similarity search
- Retrieval quality measurement

### AI Agent Observability
- Tool call tracing
- Token usage monitoring
- Execution latency
- Error analysis

## Project Goal

Document reliable engineering patterns for
developing and operating enterprise AI applications.

All examples are independently developed
educational material.
